# Useful Python Scripts

Small command-line utilities with no third-party dependencies.

## Scripts

- `password_generator.py` creates strong random passwords or passphrases.
- `file_hash.py` prints SHA-256, SHA-1, or MD5 hashes for files.
- `dedupe_csv.py` removes duplicate rows from a CSV while keeping the first copy.
- `slugify_names.py` previews or applies safe file renames.

Run any script with `--help` for options.
